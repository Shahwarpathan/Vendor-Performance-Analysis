# Vendor-Performance-Analysis
## Project Overview
This project analyzes vendor performance usiing sales and purchasing data. The objective is toidentify top-performaning vendors, understand sales trend, evaluate profitability, and provide actionable business insights.
## Objectives
- Analyze vendors sales performance
- Identify top and low-performing vendors
- Evaluate revenue nd profit contribution
- Discoiver trends and profit contribution
- Discover tredns and patterns in vendor activity
- Generate business recommendations
## Tools & Technologies
- Python
- Pandas
- Numpy
- Matplotlib
- Jupyter Notebook
## Datasets
The dataset contains Vendor-related information, including sales, purchases, costs, and performance matrics.
